## 1. How the workbook was built

The whole workbook is generated from code, so it can be rebuilt and re-checked at any time:

```bash
./venv/bin/python tableau/scripts/build_tableau_extracts.py      # 6 extracts + RetailPulse_Final.twb/.twbx
./venv/bin/python tableau/scripts/validate_tableau_extracts.py   # 20 structural/data checks
./venv/bin/python tableau/scripts/tableau_runtime_check.py       # opens every dashboard and sheet in Tableau (≈35 min)
```

- **Data:** the six validated extracts, unchanged. Every value equals the CSVs (Hyper API check). Revenue in the
  extract is BRL 13,494,400.74, and the 190 unobserved cohort cells are still NULL (blank, not 0).
- **Calculations:** all 100 registry calculations (90 measures + 10 helpers), formulas character-for-character the
  ones validated against SQL (264/264). No business definition, denominator or date range was changed.
- **Sheets:** chart type per question, as specified:
  - lines for trends; bars for rankings and comparisons
  - a stacked bar for the delivery stages; a heatmap for cohort retention
  - a scatter for the seller scorecard; one pie (one-time vs repeat); text tables for detail lists
- **Formatting:** BRL currency (`R$ #,##0.00`), percentages to 2 dp, sorted bars, value labels, tooltips with the
  supporting measures.
- **Design:** one restrained palette (orange `#D95926` primary, grey for comparison series, blue `#3987E5` for a
  second family, an orange-blue diverging scale for growth and MoM %), a light background `#F4F3EF`, white cards,
  and Tableau Book / Semibold type.
- **Dashboards:** 1400 × 1150 px fixed (detail pages 1400 × 1000). Each has a header (title, the business
  question, the period with "historical data, not live performance"), filter controls, a KPI strip, two rows of
  charts, the mandatory captions and a footer (revenue excludes freight; no cost data, so no profit; data licence).

### Data sources in the workbook

1B885FB3, see §4). Each registry data source with several related tables is therefore published as two-table
Tableau data sources. Each holds the root plus one related table and reads the same `.hyper` extract. Field names,
internal names and formulas are the registry's; a calculation appears in every Tableau data source that has its
inputs.

Tableau generated from Hyper's log, re-executes it on the extracts, and closes Tableau. Full output:

## 4. Problems found in Tableau and how they were solved

| Symptom in Tableau 2026.3.2 | Cause | Resolution |
|---|---|---|
| Error 1B885FB3 "Logical Query missing field [key (table A)] from relationOp [Extract].[table B]" on 21 sheets | Several related tables sharing the root key in one data source. Earlier KPI sheets never combined two tables, so this had not shown before | Two-table Tableau data sources (§1). Shown by test: RP Customers (one related table) never failed |
| Error D2E8DA72 on load with navigation buttons | Tableau rejects the generated `<button>` element, even a minimal one, although the public XSD defines it | No buttons. Pages are reached through the workbook tabs; tooltip-menu actions open the detail pages and lead back |
| Error D2E8DA72 on load with parameter actions | Tableau rejects `<edit-parameter-action>`, even an empty one | Detail pages driven by a parameter control (category dropdown, seller_id box) |
| Sheets 4.1 and 4.3 drew no query | seller_state on the tooltip and in the dashboard's shared seller-state filter at the same time | seller_state removed from those tooltips |
| Bisected by script, not visible in the dialog | Tableau redacts error details in its log, so each cause was isolated by opening variants of the workbook | `tableau_runtime_check.py` keeps this evidence repeatable |

A note on the "Sales Commission is not an extract" message (error 3C242D89) seen on 2026-11-28 at 13:27. It came
from Tableau's bundled **Superstore** sample (`Superstore.twb`, Tableau process 14091), opened from a scratch folder
for a screen-capture test. It did not come from RetailPulse: the RetailPulse workbook has no data source of that
name and no non-extract connection. Every RetailPulse open since then shows 0 extract errors.

## 6. Limits: what was not tested or done

- **Clicks.** No click, hover or menu choice was performed: this Mac does not allow UI scripting (Accessibility
  is off). Filter logic was tested by saving filter and parameter values into copies (§2). That the two
  click-a-state filter actions and the four menu actions fire on a click is **not tested**. Their XML follows
  Tableau's own Superstore actions, and the workbook loads with them.
- **Screenshots.** None were taken. `screencapture` returns only the desktop wallpaper because this process has
  no Screen Recording permission. No screenshot was simulated.
- **Publishing.** Not attempted from here: Save to Tableau Public needs the owner's Tableau Public sign-in in
  Tableau Desktop.
- **Table calculations** (3-month average, MoM %, rank, cumulative share) run inside Tableau after the query.
  Their inputs were checked in Tableau, and their formulas by `scripts/validate_tableau_calcs.py` (264 checks).
